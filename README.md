# Fourever You — Django Web Application

A Django-based web application dedicated to the "Fourever You" series, featuring user authentication, user sign-up, and an interactive real-time commenting system.

---

## 🚀 Features

- **User Authentication**:
  - Account Creation / Sign Up
  - Built-in Django Login & Logout system
- **Interactive Comment Section**:
  - Logged-in users can leave comments.
  - Comments display the user's email address or username.
  - Timestamped comments ordered from newest to oldest.
- **Protected Actions**:
  - Non-authenticated users are prompted to log in or register before commenting.

---

## 🛠️ Tech Stack

- **Backend**: Python 3.14, Django 6.1
- **Database**: SQLite
- **Environment Management**: Pipenv
- **Frontend**: HTML5, CSS3, Django Template Engine
